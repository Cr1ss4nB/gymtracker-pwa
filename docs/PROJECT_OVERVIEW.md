# GymTracker PWA

## Descripción
Aplicación PWA enfocada en seguimiento de rutinas de entrenamiento físico.

Permite:
- Crear rutinas personalizadas
- Usar templates prefabricadas
- Registrar entrenamientos
- Registrar peso y repeticiones
- Validaciones mediante cámara, audio y texto
- Uso offline
- Sincronización automática
- Push notifications
- Dashboard de progreso
