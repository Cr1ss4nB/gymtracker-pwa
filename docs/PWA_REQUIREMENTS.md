# Requisitos PWA

## Obligatorio

- Manifest
- Service Worker
- Offline mode
- IndexedDB
- Installable
- Responsive

---

## Funcionalidades nativas

- Cámara
- Micrófono
- Geolocalización
- Vibración
- Notificaciones push del cronometro, entrenamiento hecho, recordatorios de entrenamientos, mensajes motivacionales. 

---

## Push Notifications

Ejemplos:
- recordatorios
- validaciones
- rutina completada
- mensajes motivacionales fitness

---

## Auditoría

Herramientas:
- Lighthouse
- PWA Builder
